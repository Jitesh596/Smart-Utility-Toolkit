# Smart Utility Toolkit

A Node.js-based backend lab project that demonstrates the use of Node.js core modules through multiple mini utilities.

## 📌 About the Project

The **Smart Utility Toolkit** is a hands-on Node.js project created for **Web Dev III – Node.js & Express Backend**.

The project demonstrates fundamental backend concepts using only Node.js built-in modules. It includes a command-line calculator, custom reusable module, HTTP server, file manager, and random dice generator.

> No external npm packages or frameworks are used in this project.

## 🚀 Features

### 1. CLI Calculator

A command-line calculator using `process.argv`.

Supported operations:

- Addition
- Subtraction
- Multiplication
- Division
- Invalid operation handling

Example:

```bash
node calculator.js add 10 5
